# 🔒 Security Policy

This repository contains a profile README and its assets; it does not publish versioned releases.

## Reporting

Please report suspected vulnerabilities privately through [GitHub's private vulnerability reporting form](https://github.com/Yash-Agarwal-4a5h/Yash-Agarwal-4a5h/security/advisories/new).

Include the affected file or URL, steps to reproduce the issue, and any relevant impact. Do not disclose the details publicly until they have been reviewed. If private reporting is unavailable, use contact information published on the repository owner's GitHub profile rather than opening a public issue.
