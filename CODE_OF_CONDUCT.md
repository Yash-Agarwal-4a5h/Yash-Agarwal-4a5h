# ❤️ Code of Conduct

## Our Pledge

We are committed to making participation in this project a respectful, welcoming, and harassment-free experience for everyone.

This code of conduct applies in project spaces, including issues, pull requests, discussions, and other project-related communications.

## Expected Behavior

- Be respectful and considerate of differing viewpoints and experiences.
- Give and receive constructive feedback graciously.
- Keep discussion focused on the work and help make participation welcoming for newcomers.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Insults, threats, or deliberately intimidating behavior.
- Publishing someone else's private information without permission.
- Disruptive behavior that prevents others from participating constructively.

## Enforcement and Reporting

Project maintainers may edit or remove content that violates this code and may restrict or end a contributor's participation when necessary.

To report a concern, contact the maintainers privately using contact information published on the repository owner's GitHub profile. Please include relevant context, and do not post private information in a public issue or pull request.
