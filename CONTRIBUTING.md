# 🤝 Contributing Guide

Thank you for your interest in improving this profile repository. Contributions may include README updates, SVG banner improvements, and documentation fixes.

Please follow the [Code of Conduct](./CODE_OF_CONDUCT.md) when participating in this project.

## Getting Started

- Fork the repository and create a branch from the default branch.
- Keep changes focused and use descriptive branch names, such as `feature/banner-update`, `fix/broken-image`, or `docs/readme-update`.
- Preview the README on GitHub when changing Markdown or the banner.

## Changes and Pull Requests

- Check that local image links point to files that exist in the repository.
- Keep the profile information accurate and avoid adding private information.
- For SVG changes, verify that the file remains valid XML and that its text is readable at the displayed size.
- Describe what changed and how you checked it in the pull request.
- Keep pull requests focused and use a meaningful title.

## Commit Messages

Use a short, descriptive message. Conventional Commit prefixes are welcome:

- `docs: refresh profile README`
- `fix: remove broken banner reference`
- `style: improve profile banner`
